# Honey & Crumb Bakery — Responsive Business Landing Page

## Project Overview
Honey & Crumb Bakery is a simple fictional neighborhood bakery landing page created for **Task 2: Responsive Business Landing Page** in the Week 1 Web Development assignment.

The page focuses on clear business communication, responsive layout, simple navigation, service cards, trust-building content and a usable order/contact form.

## Requirements Covered
- Semantic HTML5 structure
- Responsive desktop, tablet and mobile layouts
- Navigation with brand, Home, Services, About and Contact links
- Primary CTA: Order Now
- Hero section with value proposition, supporting text and visual
- Four service cards
- About section
- Trust/promise strip
- Contact/order form with name, email, phone, order type and message
- HTML validation plus JavaScript form feedback
- Flexbox and CSS Grid
- Hover and focus states
- Mobile navigation
- Subtle scroll reveal animation
- Reduced-motion accessibility support
- Clean reusable CSS classes

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- CSS Grid and Flexbox

## Run Locally
No build tools are required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. For development, VS Code Live Server can also be used.
